# 🤖 Virtual Assistant

An AI-powered Virtual Assistant built to help users perform everyday tasks through natural language interactions. The assistant can answer questions, provide information, automate tasks, and improve productivity through an intuitive conversational interface.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Kundank8789/Virtual-Assistant.git
```

### Navigate to Project

```bash
cd Virtual-Assistant
```

### Install Dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file:

```env
GEMINI_API_KEY=your_api_key
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

## ▶️ Running the Application

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🎯 How It Works

1. Open the application.
2. Enter a text query or voice command.
3. The assistant processes the request using AI.
4. Receive intelligent and context-aware responses.
5. Continue the conversation naturally.
